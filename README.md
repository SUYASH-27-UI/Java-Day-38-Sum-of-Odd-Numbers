# Java Day 38 - Sum of Odd Numbers in an Array

## Description
This Java program calculates the sum of all odd numbers in an integer array.

## Example
**Array:** `{10, 15, 20, 7, 8, 3}`

**Output:** `Sum of odd numbers = 25`

## Concepts Used
- Arrays
- For Loop
- If Statement
- Modulus Operator
- Addition

## How to Run
1. Save the code as `Main.java`.
2. Compile using `javac Main.java`.
3. Run using `java Main`.
